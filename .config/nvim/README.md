# Neovim ミニマル設定

プラグインなしのシンプルで軽量なNeovim設定です。

## 📁 構成

```
.config/nvim/
├── init.lua          # メインの設定ファイル
└── lua/
    ├── options.lua   # 基本設定（表示、編集、検索など）
    └── keymaps.lua   # キーマッピング
```

## 🚀 セットアップ

### 1. シンボリックリンクを作成

```bash
./init.sh
```

または手動で：

```bash
rm -rf ~/.config/nvim
ln -sf ~/dotfiles/.config/nvim ~/.config/nvim
```

### 2. Neovimを起動

```bash
nvim
```

## ⌨️ 主なキーマッピング

### リーダーキー
- `Space` - リーダーキー

### ファイル操作
- `<leader>w` - ファイルを保存
- `<leader>q` - 終了
- `<leader>Q` - すべて強制終了
- `<leader>e` - ファイルエクスプローラーを開く（Netrw）
- `<leader>E` - 垂直分割でエクスプローラーを開く

### ウィンドウ操作
- `Ctrl+h/j/k/l` - ウィンドウ間の移動（左/下/上/右）
- `Ctrl+矢印` - ウィンドウサイズの変更
- `<leader>sv` - 垂直分割
- `<leader>sh` - 水平分割
- `<leader>se` - ウィンドウサイズを均等に
- `<leader>sx` - 現在のウィンドウを閉じる

### バッファ操作
- `Shift+h` - 前のバッファへ
- `Shift+l` - 次のバッファへ
- `<leader>bd` - 現在のバッファを閉じる
- `<leader>bo` - 他のバッファをすべて閉じる

### タブ操作
- `<leader>tn` - 新しいタブ
- `<leader>tc` - タブを閉じる
- `<leader>to` - 他のタブをすべて閉じる
- `<leader>tp` - 前のタブへ

### テキスト編集
- `<`/`>` - インデント調整（ビジュアルモードで選択を維持）
- `J`/`K` - 選択行を上下に移動（ビジュアルモード）
- `H` - 行頭へ移動
- `L` - 行末へ移動
- `<leader>a` - すべて選択

### その他
- `Esc` - 検索ハイライトをクリア / ターミナルモードから抜ける
- `Ctrl+d/u` - ページ移動（カーソルを中央に保持）

## ⚙️ 主な設定内容

### 表示
- 行番号と相対行番号を表示
- カーソル行をハイライト
- 不可視文字を表示（タブ、行末スペースなど）
- サインカラムを常に表示

### 編集
- タブ幅: 4スペース
- タブをスペースに展開
- クリップボード統合（システムクリップボードと連携）
- アンドゥファイル保存（再起動後もアンドゥ可能）

### 検索
- 大文字小文字を無視（smartcase）
- インクリメンタルサーチ
- 検索結果をハイライト

### その他
- マウスを有効化
- True colorサポート
- ウィンドウを右・下に分割
- デフォルトカラースキーム: `habamax`

## 🎨 カラースキームの変更

`lua/options.lua` の最後の方にある以下の行を編集してください：

```lua
vim.cmd([[
  colorscheme habamax
]])
```

Neovim組み込みのカラースキーム：
- `default` - デフォルト
- `habamax` - 暗めのモダンなテーマ
- `lunaperche` - 明るいテーマ
- `desert` - 砂漠カラー
- `evening` - 夕暮れカラー
- `industry` - ダークテーマ
- `koehler` - クラシックなテーマ
- `morning` - 明るいテーマ
- `pablo` - ダークテーマ
- `peachpuff` - 桃色系
- `ron` - ダークテーマ
- `shine` - 明るいテーマ
- `slate` - グレー系
- `torte` - ダークテーマ
- `zellner` - 明るいテーマ

## 📚 今後の拡張

このミニマル設定から始めて、必要に応じて以下のような拡張が可能です：

1. **プラグインマネージャー（lazy.nvim）の導入**
2. **LSPサポート** - コード補完、定義ジャンプなど
3. **Treesitter** - 高度なシンタックスハイライト
4. **Telescope** - ファジーファインダー
5. **Git統合** - gitsigns.nvimなど
6. **ファイルツリー** - nvim-tree.luaなど

## 💡 ヒント

### Netrw（組み込みファイルエクスプローラー）の使い方
- `<leader>e` でNetrwを開く
- `<CR>` - ファイル/ディレクトリを開く
- `-` - 親ディレクトリへ移動
- `%` - 新しいファイルを作成
- `d` - 新しいディレクトリを作成
- `D` - ファイル/ディレクトリを削除
- `R` - ファイル/ディレクトリをリネーム
- `i` - 表示形式を切り替え
- `s` - ソート順を切り替え

### ヘルプの表示
```vim
:help <キーワード>
```

```vim

```
